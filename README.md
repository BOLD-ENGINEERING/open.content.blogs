# Content Blogs
A developer-first blogging platform powered by GitHub and Markdown.

## Core Idea:
- Write content in markdown
- Use branches for staging/production
- Zero DevOps setup for developers

Status: Building MVP

## Local publishing

The Phase 2 worker publishes Git Markdown repositories to local sites and branch
previews. See [worker setup and commands](worker/README.md) and
[Phase 2 verification](docs/qa/phase-2/report.md).
